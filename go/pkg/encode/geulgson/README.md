# geulgson

GEUL 문서를 GSON(GEUL의 JSON 표현)으로 바꾼다.

## 보기

| 보기 | 스키마 | 손실 | 용도 |
|---|---|---|---|
| 원형 | 필요 없음 | 없음 | 디버깅, 테스트 벡터, 손으로 쓰기, 다른 언어 구현과의 교차 검증 |
| 해석 | 필요 | 있음 | 레이블과 형식을 풀어 사람이 읽기 |

## 규칙

- ID는 문자열로 쓴다. JSON 숫자는 2^53을 넘으면 정밀도가 깨진다. 표기는 GEUL-ORG의 `0x` hex(자릿수 = 폭 × 4)를 따른다.
- 모르는 레코드는 원본 WORD를 그대로 싣는다. 원형 보기에서 다시 인코딩해도 손실이 없다.
- 원형 보기의 역방향은 `decode/gsongeul`이 맡는다.
